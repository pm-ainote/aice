01시작하는 법

1. 영상 보기

강의 하나를 끝까지 봅니다. 확인 문제가 나오면 잠시 멈추고 먼저 풀어 보세요.

2. 따라 입력

「따라 입력」 노트북을 코랩에서 열고(구글 로그인 필요) 영상의 코드를 직접 입력해요.

파일을 열면 먼저 「파일 → 드라이브에 사본 저장」을 해 두세요. 내가 입력한 내용이 남고, 사본에서는 보통 경고도 뜨지 않아요.
사본 저장 전에 셀을 실행하면 「경고: 이 노트북은 Google에서 작성하지 않았습니다」가 뜨는데, 무시하고 계속하기를 누르면 진행은 가능합니다.

3. 확인 문제 → 해설

「확인 문제」를 먼저 풀고, 막힌 곳만 「해설」에서 확인해요.
