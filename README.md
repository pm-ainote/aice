# AICE 2주 합격 플랜 실습 자료

유튜브 「비개발자 PM의 AI 노트」 2주 합격 플랜의 실습 노트북, 연습 데이터, 암기카드입니다.

- 안내 페이지: https://pm-ainote.github.io/aice/ (날짜별 코랩 링크, 사용법, 업데이트 기록)
- 유튜브: https://www.youtube.com/@pm_ainote

## 구성

- `notebooks/` 날짜별 문제(`dayNN_problem`)와 해설(`dayNN_solution`), 모의고사 1회(`mock1_problem`, `mock1_solution`). 영상 N편과 Day N 이 짝입니다.
- `data/` 연습 데이터. 노트북의 준비 셀이 자동으로 내려받습니다.
- `cards/` 암기카드. 브라우저에서 열고, 복습 기록은 내 브라우저에 저장됩니다.

## 이용 조건

개인 학습용으로 자유롭게 쓰세요. 자료의 재배포·판매는 허용하지 않습니다.

개인이 만든 비공식 학습 자료이며 AICE 주최측과 무관합니다. 연습 데이터는 학습용 가짜 데이터입니다.
