14문항 함수 지도

AICE Associate 공식 샘플(분류·회귀 각 14문항)에 나오는 함수와 옵션을 문항 순서대로 모았습니다. 코드는 연습 데이터(aice_practice.csv)로 위에서부터 차례로 실행해 확인했어요. 하나씩 외울 때는 암기카드를 쓰세요.

먼저 세 가지만

괄호가 있으면 일을 시킨다

df.head() df.isnull() 처럼 무언가를 계산하거나 보여 달라고 할 때 써요.

괄호가 없으면 값을 꺼낸다

df.shape df.columns 는 이미 있는 값이에요. df.shape() 는 에러가 나요.

끝에 밑줄이면 학습 결과

best_params_ best_estimator_ feature_importances_ 는 fit 한 뒤에 생겨요. 괄호도 붙이지 않아요.

문항 순서대로

1라이브러리 불러오기데이터 분석 · Day 1
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import sklearn as sk

별칭은 문제가 정해 줘요. 분류 1번은 sklearn as sk, 회귀 1번은 pandas as pd 를 물어요.

2파일 읽고 앞부분 보기데이터 분석 · Day 1
df = pd.read_csv('aice_practice.csv')
df.head(4)

변수 이름과 행 수는 문제에 적힌 그대로 써요. head() 만 쓰면 5행이에요.

3그래프 여러 칸에 그리기데이터 분석 · Day 4
fig, axes = plt.subplots(nrows=1, ncols=2, figsize=(12, 4))
sns.histplot(data=df, x='Age', hue='Survived', ax=axes[0])
axes[0].set_title('Age')
sns.countplot(data=df, x='Pclass', ax=axes[1])

분류 3번은 subplots·ax=·set_title 빈칸이에요. 회귀 3번은 countplot 을 그려 보고 가장 많은 값을 답 변수에 저장해요.

4두 열의 관계 그래프데이터 분석 · Day 4
sns.boxplot(data=df, x='Pclass', y='Fare')
sns.jointplot(data=df, x='Age', y='Fare')

분류 4번은 boxplot, 회귀 4번은 jointplot 이에요. 그래프 함수는 모두 data=, x=, y= 로 열 이름을 넘겨요.

5이상치 행 지우기 · 번호 다시 매기기데이터 전처리 · Day 3
q1 = df['Fare'].quantile(0.25)
q3 = df['Fare'].quantile(0.75)
iqr = q3 - q1
cond = (df['Fare'] < q1 - 1.5 * iqr) | (df['Fare'] > q3 + 1.5 * iqr)
df = df.drop(df[cond].index, axis=0)
df.reset_index(drop=True, inplace=True)

분류 5번 형식이에요. 회귀 5번은 기준값으로 남길 행만 고르고(df = df[df['열'] < 300]), 필요 없는 열을 drop('열', axis=1, inplace=True) 로 지워요.

6빈칸 세고 지우기데이터 전처리 · Day 3
df.isnull().sum()
df = df.dropna()

분류·회귀 같아요. 지우지 말고 채우라고 하면 df['Age'].fillna(df['Age'].median()) 처럼 써요(공식 샘플에는 없음).

7값 묶기 · 글자를 숫자 열로데이터 전처리 · Day 3
df['Embarked'].value_counts()
df.loc[df['Embarked'].isin(['C', 'Q']), ['Embarked']] = 'other'
df = pd.get_dummies(data=df, columns=['Sex', 'Embarked'])
df.info()

분류 7번에는 열을 지우는 코드를 고치는 오류 정정이 있어요. 열은 axis=1, 행은 axis=0 이에요. 회귀 7번은 get_dummies 와 columns 가 빈칸이에요.

8문제(X)와 답(y) 나누기데이터 전처리 · Day 5
from sklearn.model_selection import train_test_split
X = df.drop('Survived', axis=1)
y = df['Survived']
X_train, X_valid, y_train, y_valid = train_test_split(X, y, test_size=0.3, random_state=7, stratify=y)

test_size·random_state 숫자는 문제가 정해 줘요. 분류에서는 stratify=y 를 넣어요. 회귀 샘플은 stratify 없이 test_size=0.2, random_state=42 예요.

9숫자 크기 맞추기(스케일링)데이터 전처리 · Day 5
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_valid = scaler.transform(X_valid)
round(np.max(X_valid))

학습용은 fit_transform, 검증용은 transform 이에요. 분류는 StandardScaler, 회귀는 RobustScaler 이고 쓰는 법은 같아요. 둘 다 이 부분을 고치는 오류 정정이에요.

10모델 만들고 학습하기AI 모델링 · Day 5
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import GridSearchCV
gs = GridSearchCV(estimator=DecisionTreeClassifier(random_state=7),
                  param_grid={'max_depth': [3, 5, 7]}, cv=3, scoring='accuracy', n_jobs=-1)
gs.fit(X_train, y_train)
gs.best_params_
rf = RandomForestClassifier(n_estimators=100, random_state=7)
rf.fit(X_train, y_train)

분류에서는 GridSearchCV 로 설정을 찾아요. 회귀 샘플은 GridSearchCV 없이 DecisionTreeRegressor·RandomForestRegressor 를 문제가 준 설정(max_depth 등)으로 바로 만들어요. 회귀에서 GridSearchCV 를 쓴다면 scoring='accuracy' 는 빼요.

11중요한 변수 보기AI 모델링 · Day 5
fi = pd.DataFrame({'feature': X.columns,
                   'importance': gs.best_estimator_.feature_importances_})
fi = fi.sort_values('importance', ascending=False)
sns.barplot(data=fi, x='importance', y='feature')

분류·회귀 모두 오류 정정이에요. 단골은 feature_importances_ 이름과 sort_index 를 sort_values 로 고치기예요. 분류에서는 best_estimator_ 의 밑줄도 봐요(회귀 샘플은 GridSearchCV 가 없어 모델에서 바로 꺼내요).

12예측하고 점수 내기AI 모델링 · Day 5
from sklearn.metrics import accuracy_score
y_pred = gs.best_estimator_.predict(X_valid)
print(accuracy_score(y_valid, y_pred))

분류는 accuracy_score(클수록 좋음), 회귀는 mean_absolute_error(작을수록 좋음)예요. 오류 정정 단골은 분류에서 accuracy → accuracy_score, pred → predict, 회귀에서 mean_absolute → mean_absolute_error, predict(X_train) → predict(X_valid) 예요.

13딥러닝 모델AI 모델링 · 딥러닝 · Day 6 · 12
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Dropout
from tensorflow.keras.callbacks import EarlyStopping
model = Sequential([
    Dense(64, activation='relu', input_dim=X_train.shape[1]),
    Dropout(0.3),
    Dense(32, activation='relu'),
    Dense(1, activation='sigmoid'),
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
es = EarlyStopping(monitor='val_loss', patience=5)
history = model.fit(X_train, y_train, epochs=30, batch_size=128,
                    validation_data=(X_valid, y_valid), callbacks=[es])

마지막 층은 정답 모양에 맞춰요. 정답이 0·1 이면 Dense(1, activation='sigmoid'), 분류 샘플처럼 to_categorical 로 두 칸을 만들면 Dense(2, activation='sigmoid')예요. 회귀는 Dense(1, activation='linear'), loss='mean_squared_error', metrics=['mse'] 예요.

14학습 곡선 그리기AI 모델링 · 딥러닝 · Day 6 · 12
plt.plot(history.history['accuracy'])
plt.plot(history.history['val_accuracy'])
plt.title('Accuracy')
plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.legend(['accuracy', 'val_accuracy'])

기록 이름은 compile 의 metrics 를 따라요. 분류는 accuracy·val_accuracy, 회귀는 mse·val_mse 예요. loss 곡선은 loss·val_loss 예요.
